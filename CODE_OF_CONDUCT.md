# Code of conduct

Be direct, specific, and respectful. Critique the fixture, the docs, and the patch. Do not insult people.

Harassment, personal attacks, and posting someone else’s private data are not acceptable. The maintainer may hide comments, lock threads, or block accounts that do that.

Report conduct problems through a private GitHub security advisory on this repository, or by contacting the maintainer on GitHub (`jishmisc28`).
